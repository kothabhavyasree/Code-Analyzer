# Code Analyzer

An AI-powered Code Analyzer built using Python, Streamlit, LangChain, and Groq.

## 🚀 Overview

The Code Analyzer helps users analyze source code and receive AI-powered feedback through an interactive Streamlit application.

## ✨ Features

- 🤖 AI-powered code analysis
- 💬 Interactive interface
- 🐛 Error and issue identification
- 💡 Code improvement suggestions
- 📖 Code explanations
- 🌐 Streamlit web application

## 🛠️ Technologies Used

- Python
- Streamlit
- LangChain
- Groq API
- LLM

## ⚙️ Installation

Clone the repository:
```bash
git clone git@github.com:kothabhavyasree/Code-Analyzer.git
```

Move into the project directory:
```bash
cd Code-Analyzer
```

Install the required packages:
```bash
pip install -r requirements.txt
```

## 🔑 API Key Configuration

Set your Groq API key as an environment variable:
```bash
export GROQ_API_KEY="your_api_key_here"
```

Do not hardcode API keys in the source code or commit them to GitHub.

## ▶️ Run the Application

Start the Streamlit application:
```bash
streamlit run code_analyzer_app.py
```

The application will open in your browser.
